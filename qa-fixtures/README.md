# QA Fixtures

These synthetic progression-stage saves are generated by `npm run qa:fixtures`.
They are not real user saves and should only be used for repeatable coverage and mobile UI checks.
The PC late-game fixture is intentionally source-shaped and broad; it covers automation, records, speedrun, Reality, Celestials, Pelle, and dense options branches so mobile browsing is tested against a large all-game save.

## Files

- `pc-normal-save.txt`: encoded PC-format Normal-stage fixture save.
- `pc-infinity-save.txt`: encoded PC-format Infinity-stage fixture save.
- `pc-eternity-save.txt`: encoded PC-format Eternity-stage fixture save.
- `pc-late-game-save.txt`: encoded PC-format late-game fixture save.
- `android-normal-save.txt`: encoded Android-format Normal-stage fixture save.
- `android-infinity-save.txt`: encoded Android-format Infinity-stage fixture save.
- `android-eternity-save.txt`: encoded Android-format Eternity-stage fixture save.
- `android-late-game-save.txt`: encoded Android-format late-game fixture save.
- Matching `*-coverage-report.json` files: expected coverage summaries for each fixture.
- `manifest.json`: compact index of fixture expectations.

## Manual QA

Open https://beurke1.github.io/antimatter-dimensions-mobile-save-editor/ on the target device, paste a fixture save into Import, and tap Decode.
The app should show the matching path totals from `manifest.json`, no safety errors, category tabs matching the save stage, and a Readiness state that allows encoding.
